# **App Name**: NutriAI - Assistente Pessoal de Nutrição e Fitness com IA

## Core Features:

- Perfil do Utilizador & Metas: Permite aos utilizadores criar um perfil detalhado (altura, peso, idade, sexo, nível de atividade física) e definir objetivos claros (perda de peso, ganho de massa muscular, manutenção, melhoria de performance). Calcula automaticamente as necessidades calóricas diárias (TDEE) e macronutrientes com base no perfil e objetivo, com a IA a ajustar estas metas ao longo do tempo.
- Diário Alimentar Inteligente: Oferece uma interface intuitiva para adicionar manualmente alimentos e refeições (pequeno-almoço, almoço, jantar, lanches). Inclui uma base de dados nutricional integrada para pesquisa de alimentos e um scanner de código de barras para identificar produtos e preencher automaticamente os dados nutricionais, simplificando o registo.
- Visualização de Progresso Nutricional: Apresenta visualizações claras do progresso diário em relação às metas de calorias e nutrientes, utilizando gráficos de barras, círculos de progresso e outros elementos visuais para uma fácil compreensão da aderência aos objetivos.
- Nutricionista Virtual com IA: Um tool inteligente que se integra com uma API de modelo de linguagem (ex.: OpenAI GPT-4o, Anthropic Claude) para atuar como um coach virtual. A IA analisa o diário alimentar, a evolução do peso e os objetivos do utilizador para fornecer resumos diários/semanais do progresso, dar sugestões personalizadas de refeições, alertar sobre défices ou excedentes nutricionais e responder a perguntas gerais sobre nutrição e exercício físico. Também ajusta as metas calóricas com base na evolução do peso registada pelo utilizador.
- Registo e Análise de Evolução: Permite aos utilizadores registar o peso corporal e outras medidas corporais ao longo do tempo. Apresenta gráficos detalhados para visualizar a evolução do peso e a aderência às calorias e outras metas, oferecendo insights sobre o progresso geral.
- Análise de Fisiologia e Exercício para Pacientes Oncológicos: Um módulo dedicado com uma interface especializada para pacientes oncológicos. Este tool fornece uma análise detalhada e precisa de todos os dados fornecidos, incluindo cálculos avançados de VO2 max, carga de treino necessária, fisiologia do exercício e dados cinesiológicos. Futuramente, integrará documentos de prescrição de exercício de especialistas para oferecer cálculos ainda mais precisos e personalizados, permitindo uma prescrição de treino segura e eficaz para esta população específica.
- Persistência Segura de Dados: Funcionalidade de base de dados para armazenar de forma segura perfis de utilizador, diários alimentares, dados de progresso, interações com a IA e dados específicos de pacientes oncológicos, garantindo que os dados são guardados e acessíveis em todas as sessões. Utilizará SwiftData ou Core Data para persistência local.

## Style Guidelines:

- Esquema de cores claras para uma estética limpa e profissional. Cor primária: Azul fresco e confiável (#1F66B3), simbolizando orientação e saúde. Cor de fundo: Cinza-azul muito claro e subtil (#ECF1F6) para manter a calma e o foco. Cor de destaque: Verde-ciano vibrante (#2FD4ED) para realçar informações chave e chamadas para ação.
- Fonte para títulos e corpo do texto: 'Inter' (sans-serif) pela sua estética moderna, altamente legível e objetiva, adequada para a apresentação clara de dados e informações.
- Utilizar um conjunto consistente de ícones vetoriais limpos e minimalistas que sejam fáceis de entender e melhorem a visualização de dados, focando em conceitos como alimentação, progresso, objetivos e análise.
- Empregar uma estrutura de layout responsiva baseada em cartões com bastante espaço em branco para garantir a clareza dos dados e uma experiência de navegação intuitiva em diferentes tamanhos de dispositivos. Priorizar uma hierarquia visual clara para resumos diários e progresso de metas.
- Incorporar animações subtis e funcionais para feedback sobre as ações do utilizador (ex.: registo bem-sucedido, atualizações de dados) e transições suaves entre os elementos do dashboard e gráficos de progresso para melhorar a experiência do utilizador sem distrair.
